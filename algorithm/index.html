代码随想录刷题笔记总览

这是一套面向复习和面试准备的算法笔记。笔记不按题号整理，而是按“题型识别 → 核心方法 → 代码写法 → 典型题 → 易错点”整理。

刷题前置基础

  • 算法刷题 Python 常用数据类型速查：整理 list、str、tuple、set、dict、Counter、deque、heapq 的常用场景和复杂度。

快速入口

链表 dummy head、快慢指针、链表反转 指针变化与边界情况
哈希表 set、dict、Counter、defaultdict 存在性判断与频率统计

笔记写法

每篇模块笔记统一采用以下结构：

  1. 什么时候用这个方法
  2. 题型识别信号
  3. 核心方法和代码写法
  4. 典型题目如何套用
  5. 易错点
  6. 复习时只看这一节

快速判断题型

  • 看到“连续子数组 / 连续子串”，优先考虑滑动窗口、前缀和、单调队列。
  • 看到“有序数组 / 搜索边界”，优先考虑二分查找。
  • 看到“求所有方案”，优先考虑回溯或动态规划。
  • 看到“最大值 / 最小值 / 方案数”，优先考虑动态规划、贪心或图论。
  • 看到“最近更大 / 最近更小”，优先考虑单调栈。
  • 看到“连通性 / 分组 / 是否成环”，优先考虑并查集或 DFS/BFS。
  • 看到“依赖顺序 / 课程安排 / 先修关系”，优先考虑拓扑排序。
