代码随想录刷题笔记：链表核心套路

1. 模块总览

链表题的核心不是“遍历”，而是“指针关系”。链表不像数组一样可以通过下标随机访问，每一步都要通过 next 找到后继节点。

链表题常考：

  • dummy head：统一处理头节点被删除、插入、交换的情况。
  • 快慢指针：找中点、找倒数第 N 个节点、判断是否有环。
  • 链表反转：很多链表题的基础操作。
  • 局部重连：交换节点、两两翻转、合并链表。
  • 环与相交：用指针相遇来消除长度差。

写链表题时，先画图，再写代码。每一次修改 next 指针前，都要确认是否会丢失后续链表。

2. 题型识别信号

看到这些关键词时，可以优先联想到对应方法：

  • 删除节点、可能删除头节点：dummy head。
  • 倒数第 N 个节点、中间节点、是否有环：快慢指针。
  • 反转链表、局部反转、两两交换：反转模板或局部重连。
  • 两个链表是否相交：双指针切换链表。
  • 环的入口：快慢指针相遇后，再找入口。
  • 合并两个有序链表：dummy head + 尾指针。

先问自己四个问题：

  1. 头节点是否可能被修改？如果可能，用 dummy head。
  2. 是否需要找相对位置？例如倒数第 N 个、中点、环入口。
  3. 是否需要改变节点连接关系？如果需要，先保存后继节点。
  4. 题目要返回的是原头节点、dummy 后继，还是某个新头节点？

3. 核心方法

3.1 dummy head

常见场景：

  • 删除链表元素
  • 删除倒数第 N 个节点
  • 合并链表
  • 两两交换节点
  • 需要返回可能变化的新头节点

3.2 快慢指针

快慢指针常用来制造距离差或速度差。

常见用法：

  • 找中点：slow 每次走一步，fast 每次走两步。
  • 找倒数第 N 个节点：先让 fast 走 N 步，再让 slow 和 fast 同时走。
  • 判断是否有环：如果有环，快慢指针一定会相遇。

快慢指针的关键是循环条件。只要涉及 fast.next.next，就要先保证 fast 和 fast.next 不为空。

3.3 链表反转

反转链表要维护三个指针：

  • prev：已经反转部分的头
  • cur：当前要处理的节点
  • nxt：提前保存 cur.next，防止断链后找不到后续节点

3.5 环与相交

环和相交题的精髓是“让两个指针走过同样长度”。

链表相交：

  • 指针 pA 从 A 走到尾后切到 B。
  • 指针 pB 从 B 走到尾后切到 A。
  • 如果相交，它们会在交点相遇；如果不相交，最终一起到 None。

环入口：

  • 快慢指针先在环内相遇。
  • 一个指针从头出发，另一个从相遇点出发。
  • 两者每次走一步，再次相遇处就是环入口。

这个结论来自路径长度关系，复习时不必每次重推，但要记住第二阶段是“一起走一步”。

6. 易错点

  • 删除节点时，通常要操作前驱节点的 next，所以遍历条件常写成 while cur.next。
  • 头节点可能变化时，优先使用 dummy head，最后返回 dummy.next。
  • 反转链表必须先保存 nxt = cur.next，否则后续节点会丢。
  • 快慢指针循环条件要保护 fast.next.next，常用 while fast and fast.next。
  • 删除倒数第 N 个节点时，slow 应该停在待删除节点的前一个节点。
  • 两两交换节点时，交换后 prev 要移动到这一组的尾节点，也就是原来的 first。
  • 相交链表比较的是节点对象是否相同，不是节点值是否相同。
  • 环形链表里不能用节点值判断是否走过，应该比较节点引用，或者用集合存节点对象。
  • Python 中不要用 if node.val 判断节点是否存在，节点值可能是 0。应该写 if node。
  • 写局部重连时，先画出修改前后的指针图，再决定赋值顺序。

7. 复习时只看这一节

  • 头节点可能被删、被换、被合并：先建 dummy = ListNode(0, head)。
  • 删除节点：找前驱，改 prev.next。
  • 反转链表：nxt = cur.next，cur.next = prev，prev = cur，cur = nxt。
  • 找中点、找倒数、判断环：快慢指针。
  • 删除倒数第 N 个：fast 先走 N 步，slow 停在待删除节点前驱。
  • 相交链表：两个指针走完自己的链表后切到对方链表。
  • 环入口：快慢指针先相遇，再从头和相遇点一起走。
  • 只要要改 next，先问一句：后面的链表有没有被我保存下来？

链表题最值得练的是“指针含义”。代码写完后，可以对每个指针说一句话：它现在指向哪里，它下一步要承担什么角色。
