1. 怎么看回溯题

回溯本质是 暴力搜索 + 有条件地撤销选择。它适合处理“要把所有可能方案列出来”的题，比如：

  • 从一堆数里选若干个，返回所有组合。
  • 把字符串切成若干段，要求每段满足某种条件。
  • 返回所有子集、所有排列。
  • 在棋盘上放皇后、填数独。

回溯里最常见的三个变量：

  • path：当前已经选择的内容。
  • ans：所有合法答案。
  • start_index 或 used：控制下一步可以从哪里选，避免重复或者保证顺序。

2. 组合问题：用 start_index 保证不回头

组合问题的特点是：结果不关心顺序。[1, 2] 和 [2, 1] 是同一个组合，所以搜索时必须保证每个数字只往后选。

这里 rest 表示还差多少和。每选一个 x，下一层就变成 rest - x。如果 rest < 0，说明这条路已经超了，直接返回。

组合题的复习重点是：不回头，所以用 start_index；要控制长度，就用 len(path)；要控制和，就额外带一个 rest。

但注意，它不是说重复数字永远不能用。如果第一个 1 已经被上一层选进 path，下一层仍然可以继续选第二个 1。所以判断里必须是 i > start，不是简单地 i > 0。

6. 排列问题：用 used 控制每个位置选谁

排列问题的特点是：顺序有意义。[1, 2] 和 [2, 1] 是两个不同排列，所以不能用 start_index 控制不回头。

这里的 used[i] 表示 nums[i] 是否已经在当前排列里。比如当前 path = [1, 3]，那么下一层就不能再选 1 或 3，只能选还没用过的数。

47. 全排列 II 数组里有重复数字。比如 [1, 1, 2]，两个 1 如果不处理，会产生重复排列。先排序，然后同一层跳过重复分支：

这句比组合去重更容易混：

它的意思是：如果当前数字和前一个数字相同，并且前一个相同数字在这一层还没被用过，那当前这个重复数字就不要先开分支。

比如 [1a, 1b, 2]，在同一层如果 1a 没用过，就不允许先用 1b，否则会和先用 1a 的分支重复。
但如果 1a 已经在当前路径里，比如 path = [1a]，下一层当然可以用 1b，组成 [1a, 1b, 2]。

排列题的复习重点是：每一层都从头遍历数组，用 used 判断当前元素是否已经放进 path。

7. 棋盘问题：按行推进，快速判断当前位置能不能放

棋盘类回溯的特点是：每一层通常处理一行、一个格子或一个位置。判断合法时不要每次扫描整个棋盘，能用集合就用集合。

  • 组合里剩余数字不够选，提前停。
  • 组合总和里 x > rest，后面更大，直接 break。
  • IP 地址里剩余字符太少或太多，直接返回。
  • N 皇后里列或对角线冲突，直接跳过。

回溯题写完后可以用三个问题检查：

  1. 当前 path 什么时候算答案？
  2. 下一层递归参数怎么变化？
  3. append 之后有没有对应的 pop？

9. 复习总览

  • 回溯就是在搜索树上做选择、递归、撤销选择。
  • path 记录当前路径，ans 记录所有答案。
  • 组合问题不关心顺序，用 start_index 保证不回头。
  • 组合总和能重复选时递归 dfs(i, rest - x)；不能重复选时递归 dfs(i + 1, rest - x)。
  • 切割问题里 start 是下一段起点，end 是当前切割终点。
  • 子集问题每个节点都是答案，所以进入递归先 ans.append(path[:])。
  • 排列问题顺序有意义，每层都从头遍历数组，用 used 防止同一下标重复使用。
  • 有重复元素时先排序，再做同层去重。
  • 棋盘问题通常一层处理一行或一个空格，用集合加速合法性判断。
  • path.append(...) 和 path.pop() 必须成对出现；答案要存 path[:]，不要直接存 path。

回溯的难点不在代码长，而在“这一层到底代表什么”。复习时先把搜索树画出来，再决定用 start_index 还是 used，最后再写递归。
