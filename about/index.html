01 / 主项目

Pi Zaya

Windows 测试版

本地论文阅读与跨文献分析

PythonFastAPIReactRAG
项目用途
导入多篇 PDF 后，可以围绕文献提问、比较不同论文的方法与实验，并整理阅读笔记。回答附有引用，可跳转到对应原文；证据矩阵用于汇总各篇论文的结果和局限。
完成的工作
负责 PDF 解析、文献检索、Agent 工具调用、阅读界面和 Windows 安装包。解析时保留页码、公式和段落信息，方便从回答定位到原文。
使用与进展
已发布 Windows 测试版，可直接安装使用，无需另装 Python。源码、安装包和使用说明见下方链接。
下载 Windows 版 ↗GitHub ↗项目介绍 →
技术说明
  • 后端使用 Python / FastAPI，前端使用 React，文献检索采用 BM25。
  • 单篇与文献篮范围另有 BM25＋向量混合检索的开发实现，具体可用能力以发布版本为准。
  • 跨论文比较需要核对任务、数据集与评价指标；原文缺少的信息不补写为确定结论。
02 / 企业命题

面向 EDA 扫描链插入的 LLM Agent

广立微命题 · 比赛进行中

扫描链插入、脚本修复与结果检查

PythonLLMDockerYosys / EQY
项目用途
广立微企业命题项目。根据设计要求、网表和单元库生成扫描链插入脚本，调用 EDA 工具执行，再根据报错修复脚本、检查网表和交付文件。
完成的工作
负责需求解析、模型与工具接入、错误诊断、修复状态管理和验收检查，并实现执行预算控制、结构网表解析及兼容回退。
使用与进展
比赛进行中，已完成公开案例的端到端运行与交付验证。竞赛代码和原始材料不公开；当前验证不代表隐藏题成绩或工业签核。
查看工作流程 →
技术说明
  • 模型提出命令或局部补丁，程序检查引用依据、修改对象和约束，再交由工具执行。
  • 等价检查的结论限于所使用的模型与配置，不能代替任意设计或时序条件下的验证。

检查诊断依据

每条诊断关联具体证据，检查引用是否存在、是否支持对应修改。

保存修复版本

用哈希核对修改基线，分别保存候选与已验证版本，失败修改不覆盖已通过的状态。

控制执行开销

为解析和工具调用设置预算，在资源允许时重叠部分任务，遇到不支持的语法则回退处理。

03 / 持续研究

Pi Research

在线演示

个性化论文发现与研究跟踪

TypeScriptReactWorkers / D1
项目用途
按研究方向持续检索论文，提供摘要与推荐理由。用户可以保存、暂缓或排除候选，并记录反馈；已收集的论文可用于整理研究地图和后续阅读路径。
完成的工作
负责多源检索、论文去重、模型筛选、反馈记录和网页界面。检索与分析作为异步任务运行，保存候选和处理进度，任务中断后可以接续。
使用与进展
提供在线演示和公开源码。页面可直接访问，模型分析功能需要配置相应服务。
在线演示 ↗GitHub ↗
技术说明
  • 使用 TypeScript、React、Cloudflare Workers / D1，保存研究空间、论文、反馈和任务状态。
  • 检索记录已探索的来源与查询，重试时复用已经完成的工作。
  • 用户明确填写的偏好与系统推断分开记录；检索范围取决于数据源及接口可用性。
04 / 科研工具

Pi Translator

Edge 商店已上架

网页、PDF 与 Overleaf 翻译扩展

TypeScriptManifest V3PDF.js
项目用途
在阅读页面中划词、框选区域或翻译全文，支持原文译文对照。针对科研材料保留 LaTeX 公式、命令和引用结构，译文可复制或导出。
完成的工作
负责浏览器扩展、PDF 阅读器接入、公式保护、长文本分段、流式翻译和中断续译，并完成 Edge 商店发布。
使用与进展
已上架 Edge 商店，源码公开。使用时需配置兼容 API；普通文字翻译与图像识别可按需要选择模型。
Edge 商店 ↗GitHub ↗
技术说明
  • 扩展使用 TypeScript、Manifest V3 和 PDF.js。
  • 有文字层的 PDF 优先提取文字；扫描件或复杂区域在确认选区后交给视觉模型处理。
  • 长文本按段处理并显示进度，支持中断后继续。不同 PDF 的双栏顺序和公式提取效果会有差异。
